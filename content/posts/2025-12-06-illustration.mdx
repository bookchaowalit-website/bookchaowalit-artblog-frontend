# Illustration คืออะไร (สรุปสั้น)
Illustration คือการสร้างภาพเพื่อสื่อความหมายหรือเสริมเนื้อหา — ใช้ได้ในหนังสือ, บทความ, โฆษณา, เกม และงาน concept art เป็นต้น.

## ตัวอย่างสไตล์ที่พบบ่อย
- **Editorial illustration** — เน้นเล่าเรื่องสั้นๆ เสริมบทความ.
- **Children’s book** — รูปน่ารัก สีสด และเรื่องราวที่เข้าใจง่าย.
- **Concept / Character illustration** — สำหรับเกม/อนิเมชัน โฟกัสที่คาแรคเตอร์และการออกแบบ.
- **Vector / Flat illustration** — ใช้ใน UI และงานโฆษณา ข้อดีคือแก้ไขขนาดได้ไม่สูญเสียคุณภาพ.

## เทคนิคที่ควรโฟกัส
1. **Composition & silhouette** — ให้รูปอ่านง่ายจากระยะไกล.
2. **Color theory** — เลือกพาเลตที่สื่ออารมณ์.
3. **Linework / Value** — คอนทราสต์ช่วยให้จุดสนใจเด่น.
4. **Storytelling** — ภาพต้องเล่าเรื่องหรือเสริมข้อความ.
5. **Workflow** — sketch → refine → color → polish.

## เครื่องมือที่แนะนำ
- Procreate (iPad) — เหมาะสำหรับงานพกพาและ speedpainting.
- Adobe Photoshop / Illustrator — มาตรฐานอุตสาหกรรม.
- Clip Studio Paint — ดีสำหรับคอมมิคและงานเส้น.
- Wacom หรือ iPad + Apple Pencil.

## Mini-tutorial: วาด Character Portrait (5 ขั้น)
1. ร่าง silhouette แบบง่าย (shape ใหญ่ก่อน).
2. หา pose และ expression ที่สื่ออารมณ์.
3. ลากเส้นละเอียดและไฮไลท์ส่วนสำคัญ.
4. เติมสีฐานและกำหนดค่า value.
5. ลงรายละเอียด แสง เงา และ texture เล็กน้อย.

## การใช้งานเชิงพาณิชย์
- ส่งไฟล์ PNG/TIFF สำหรับงานพิมพ์ (300 DPI).
- ส่งไฟล์ SVG/PDF สำหรับ vector.
- ระบุ license ชัดเจน (exclusive / non-exclusive / royalty-free).
